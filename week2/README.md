# EduMinerva — Week 2

Interactive HTML + CSS + JavaScript assignment. Run with an HTTP server (fetch needs HTTP): python -m http.server 3000, then visit http://localhost:3000.

This directory is self-contained. Copy its contents to the root of your week2 GitHub branch. On Vercel choose Other, no build command, and output directory ` . ` (current directory, without spaces). No API keys needed.

Content and images adapted from https://www.eduminerva.in/. Visual direction inspired by https://landonorris.com/; no Lando Norris assets are included. This is an independent student assignment, not the official EduMinerva website.
