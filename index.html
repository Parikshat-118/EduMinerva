A FEW THINGS TO KNOW

New here?
You’re in good company.

No perfect code required.
Just the willingness to try.

Do I need any coding experience?+

No. Week 1 starts with HTML and CSS fundamentals. All you need is a browser, a code editor and a little time to practise.

What will I actually build?+

A responsive personal portfolio or an EduMinerva event landing page. In Week 2, you’ll add JavaScript interactions and share your project on GitHub.

What tools do I need?+

A modern browser and a code editor such as VS Code. Use your browser’s DevTools to inspect elements and test mobile layouts. You’ll also need a GitHub account to share your work.

Can I learn at my own pace?+

Yes. The linked videos are available whenever you want to practise. Your resource checklist is saved in this browser so you can pick up where you left off.
