# EduMinerva — Week 1

Responsive HTML + CSS assignment. No JavaScript or npm dependencies. Open index.html directly or serve this directory with any static server.

This directory is self-contained. Copy its contents to the root of your week1 GitHub branch. On Vercel choose Other, no build command, and output directory ` . ` (current directory, without spaces). No API keys needed.

Content and images adapted from https://www.eduminerva.in/. Visual direction inspired by https://landonorris.com/; no Lando Norris assets are included. This is an independent student assignment, not the official EduMinerva website.
